# **App Name**: RR Realty Hub

## Core Features:

- Advanced Property Search: Implement a smart filter system to allow users to find properties based on location, property type, status (for sale/for rent), price range, number of bedrooms/bathrooms, property size, amenities, and keywords. Provides auto-update results and a reset filter button.
- Property Detail Pages: Showcase high-quality image galleries, property highlights (price, size, status, type), key features (bedrooms, bathrooms, amenities), map location (Google Maps), contact/inquiry form, and related property suggestions.
- Admin Panel: Enable admins to add/edit/delete properties, manage page content, blog posts, inquiries, media, and SEO settings through a dedicated dashboard.
- Supabase Integration: Utilize Supabase for real-time updates, authentication (JWT secure login), and file storage to ensure data security and efficient content delivery.
- SEO Optimization: Optimize the website with dynamic metadata, schema, Open Graph tags, and a sitemap to improve search engine visibility.

## Style Guidelines:

- Primary color: #0E2D52 to convey trust and professionalism, aligning with the corporate nature of real estate.
- Secondary color: #83B0AA offering a clean and modern backdrop.
- Accent color: Soft green (#8AC926), an analogous hue to navy blue, used for call-to-actions to attract user attention.
- Font: 'Inter', a grotesque-style sans-serif for a modern and neutral look, suitable for both headlines and body text.
- Use a set of modern and professional icons to represent property features, amenities, and navigation elements. Ensure consistency in style and size across the site.
- Implement a spacious, section-based layout with clear CTAs to guide users through the site. Use a sticky header for easy navigation and incorporate a footer with a newsletter signup and contact information.
- Incorporate subtle transitions and hover effects to enhance user engagement without being distracting. For example, a gentle fade-in effect for new content or a slight scale-up on hover for interactive elements.
